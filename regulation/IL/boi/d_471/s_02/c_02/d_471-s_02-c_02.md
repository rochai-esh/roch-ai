# סעיף 2 - הגדרות

**"תיקון רישום"** — ראו תת-סעיפים.

**"חברת כרטיסי אשראי"** — תאגיד עזר המנפיק (לבד או במשותף) כרטיסי חיוב ו/או סולק עם ספקים.

**"כרטיס חיוב" "לקוח"** — כהגדרתו בחוק.

**"ריבית ליבור"** — London Inter Bank Offered Rate הנהוג בתאגיד בנקאי השולט בחברת כרטיסי האשראי.

**"ריבית פריים"** — שיעור ריבית בסיסית הנהוגה בתאגיד בנקאי השולט בחברת כרטיסי האשראי.
